# 개요

Unity로 만든 2D 메트로바니아 액션 게임 — 전투·세이브·탐험 시스템을 직접 설계하고 구현한 포트폴리오 프로젝트

# 소개

VEINWORK는 Unity와 C#으로 개발한 2D 메트로바니아 게임입니다. 플레이어 조작, 여러 무기를 이용한 전투, JSON 세이브 시스템, 적 AI, NPC 상점까지 게임의 핵심 루프(전투 → 보상 → 소비 → 저장)를 구성하는 시스템을 전부 직접 설계하고 구현했습니다.

사용 툴 : Unity
언어 : C#
장르 : 플랫포머 2D스크롤러 메트로바니아

# 조작법

좌우 이동 : A와 D
점프 : 스페이스바
달리기 : Shift + 이동키
공격 : 마우스 좌 클릭
무기 교체 : 단축키 1번 2번 3번
대화 및 저장 : W

# 주요 시스템

1. 세이브 시스템

2. Json은 클래스를 저장할 수 없다는 문제를 무기의 이름(문자열)만 저장하고 로드 시 저장해둔 데이터에서 이름으로 복원하는 방식으로 해결했습니다.

3. 슬롯 4개, 슬롯별 json / savemap.json으 파일 분리

4. 가로등 상호작용으로 저장하는 세이브 포인트 방식

5. 씬 이름 규칙을 챕터와 번호로 정렬

6. 씬 전환 시 임시 데이터를 클래스에 전달 후 복제해서 따로 두개로 저장

# 애니메이션 이벤트 기반 공격

1.히트박스 활성 타이밍: 애니메이션 이벤트로 호출

2. 대검 3타 콤보: 입력 대기 지점에 이벤트를 넣어 콤보 유지할건지 마우스 클릭여부로 판단

3. 공격 애니메이션들을 애니메이터 태그로 묶어 종료는 하나로 통일

4. 좌우반전(음수는 localScale 변함해주기) 시 히트박스 크기 보정

# 무기 시스템

1. 무기 추가는 데이터 등록 + 애니메이션 연결

2. 넉백 세기를 무기 데이터로 해서 무기마다 타격감 다름

3. 세이브랑 상점, 스왑이 전부 같은 시스템으로 구조가 짜여있음

# 적 AI

1. 추격형은 OverlapCircle 기능으로 범위 감지 + Raycast 벽 뒤 시야 차단 + 일정 시간 대기 한다 추격 시작

2. 순찰형: 두 지점 왕복 이동

# NPC 대화랑 상점 : 공용 UI와 NPC별 데이터 분리

1.범위 감지 → 조작 잠금 → 대사 출력 → 선택 UI → 상점 위임 → 조작 복귀

2.상점 UI는 씬에 하나만 두고, 각 NPC는 자신만의 품목 배열 소유 자신이 가진 품목의 수(배열)만큼 구매 버튼 생성

3. 구매하면 돈 검사하고 중복 검사하고 빈 슬롯에 지급 순서

# 플레이어 조작감

1. 코요테 타임: 플랫폼 끝에서 떨어진 직후에도 짧은 시간 점프 허용

2. 점프: 점프 중 키를 떼면 상승 속도 감쇠 → 누르는 길이로 높이 조절

3. 피격 시 포물선 넉백 + 무적 프레임

# 문제 및 해결

문제 > 원인 > 해결 순서

1. 무기 데이터가 저장되지 않았음 > 장되지 않음	클래스 참조는 JSON 직렬화 불가능 하다는걸 알음 > 이름 문자열 저장 로드할떄 저장해둔 데이터에서 문자열 찾아서 복원

2. 히트박스 판정 범위가 깨짐 > 좌우 반전용 음수 localScale이 크기 계산에 전파되며 오류가 남 > Mathf.Abs(lossyScale)로 판정 크기 양수 고정하는걸로 해결

3. 공격 애니메이션이 씹히거나 캐릭터가 멈춤 > Any State 화살표의 Bool 조건이 공격 상태를 매 프레임 덮어써버림 > 공격 시작 시 상태 Bool 전체 해제 + 공격 중 애니메이션 갱신 차단해버림으로 해결

4. 콤보 타이밍이 모션과 어긋남 > 코드 타이머와 애니메이션 재생 시점 불일치하고 계산도 힘듦 > 애니메이션 이벤트로 모션 입력 대기를 만듦

5. 적이 벽 너머 플레이어를 감지 > 범위 감지만 사용 > Raycast로 시야 차단 판정 추가

6. UI 닫은 뒤 조작이 안됌 > 정리 함수 중간의 null 참조 예외로 조작을 다시 돌려주는 코드가 실행 안 됨 > null 제외처리로 해제 코드까지 반드시 도달하도록 수정

7. 상점 버튼이 전부 마지막 품목을 구매해버림 > 클로저가 루프 변수 자체를 캡처 > 루프 안 지역 변수로 값 복사 후 캡처하도록 하니깐 해결

# 사용 기술

1. JSON 직렬화 + ID로 읽어서 불러오기

2. 애니메이션 이벤트

3. 코요테 타임 + 눌렀을때 점프 변하게(플랫포머)

4. 코루틴 기반 UI 연출(페이드 인 아웃)

5. UI 생성 (HP 하트, 상점 버튼) + 클로저 캡처 처리

6. 정적 클래스를 이용한 씬 간 데이터 전달해서 플레이어 유지

# 개선 계획

1. 유저 스킬 6종 + 보스 2종 추가 (스프라이트 완성, 구현 예정)

2. UI 연출의 프레임 의존 타이머를 Time.deltaTime 기반으로 통일(이거 pc 사향에 따라 달라지는 문제 때문에)

3. 상점 버튼 Destroy랑 Instantiate를 오브젝트 풀링으로 교체(오브젝트 풀링이 최적화에 좋음)

4. chardata에 모인 이동 + 전투 + UI를 각각의 컴포넌트로 분리
